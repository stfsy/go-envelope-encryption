# Security Policy

## Supported Versions

Only the latest minor release receives active security patches.

| Version | Supported          |
| :---    | :---               |
| >= 0.1  | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of `go-envelope-encryption` very seriously. If you discover a potential vulnerability, please report it responsibly.

### How to Report

- **Preferred**: Use [GitHub Private Vulnerability Reporting](https://github.com/stfsy/go-envelope-encryption/security/advisories/new) on this repository.

**Please do NOT file public GitHub issues for undisclosed security vulnerabilities.**

### What to Include

To help us triage and resolve the issue quickly, please provide:
1. Description of the vulnerability and attack vector.
2. Steps to reproduce or a minimal proof of concept.
3. Affected components (e.g. wire format parsing, keyset handling, KMS envelope encryption).
4. Proposed fix or mitigation, if available.

### Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Status & Triage Update**: Within 7 business days.
- **Coordinated Disclosure**: Fixes will be prepared in private and released alongside a security advisory and CVE assignment where appropriate.
